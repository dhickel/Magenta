# Public Alpha Remediation Implementation Notes

## Purpose

This file is a shared, append-only coordination surface for agents executing the public-alpha remediation sprint plans. It is not source of truth over code or tests. Use it to record cross-domain discoveries, changed assumptions, validation gotchas, and decisions that later domain agents should see.

## Rules

- Append dated notes; do not rewrite another agent's notes except to correct an obvious typo in the same turn.
- Link to code, tests, `.internal-dev` artifacts, and commits when available.
- If a note changes scope or defers work, record the user-approved decision in the relevant domain plan and `progress.md` too.
- Do not use this file to skip a planned finding. Skips require an explicit user decision and an entry in `no-action-registry.md`.
