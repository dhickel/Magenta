# Subplan 02: Playwright Harness

## Goal

Create a reusable focused Playwright harness for public page and critical HTMX workflow validation.

## Implementation Steps

1. Reuse existing Playwright availability and live-app requirement.
2. Add config/specs for public page reachability, mobile agent shell, plan mutation persistence, and workflow critical flow.
3. Document invocation and required running app.
4. Ensure browser tests can run as focused validation, not mandatory broad campaign.

## Validation

Harness can be run by a validation agent against a live app and produces actionable failures.
