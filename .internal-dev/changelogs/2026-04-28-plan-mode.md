Change Summary
Added chat-scoped plan mode with persisted execution plans, a plan_save model tool, command-driven execution, and a minimal chat UI status banner.

Behavioral Impact
Users can enter plan mode with /plan, have the model save a plan through plan_save, execute it with /exec-plan, clear chat context before execution with /clr-exec-plan, or abandon it with /exit-plan.

Risks
Plan saving depends on model tool-calling support because v1 intentionally does not parse plain text plans.

Follow-up Items
Consider adding execution step progress tracking only after the basic plan lifecycle proves useful.
